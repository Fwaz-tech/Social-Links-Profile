# Social Links Profile

My solution to the **Social Links Profile** challenge from [Frontend Mentor](https://www.frontendmentor.io/).

## Built With

* HTML5
* CSS3

## What I Learned

This was my first project after learning HTML and CSS. I practiced using Flexbox, custom fonts, and CSS styling to recreate the provided design.

## Responsive Design

The design was provided for two viewport sizes:

* Mobile: 375px
* Desktop: 1440px

The layout worked well at both sizes, so I didn't need to add any extra media queries.
